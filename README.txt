WEBSITE BÓ HOA TƯƠNG TÁC
- Mở index.html để xem bản demo (một số trình duyệt có thể chặn file cục bộ; nên tải lên hosting).
- assets/bouquet.jpg là khung hình lấy từ video bạn gửi, dùng làm ảnh nền để giữ nguyên hình ảnh bó hoa.
- Nút Chỉnh sửa cho nhập người nhận/lời nhắn; Tạo thiệp mở thiệp và hỗ trợ chia sẻ lời chúc.

ĐƯA LÊN MẠNG BẰNG GITHUB PAGES (miễn phí)
1. Đăng nhập GitHub và tạo repository mới, ví dụ flower-greeting.
2. Tải toàn bộ nội dung trong thư mục này lên repository, giữ nguyên thư mục assets.
3. Vào Settings > Pages.
4. Trong Build and deployment, chọn Deploy from a branch; chọn branch main và folder /(root), rồi Save.
5. Đợi trang được xuất bản, địa chỉ thường có dạng https://TEN-TAI-KHOAN.github.io/flower-greeting/.
6. Mở địa chỉ đó để kiểm tra trên điện thoại.
7. Tạo QR: mở trang tạo QR đáng tin cậy, nhập URL website đã xuất bản rồi tải QR PNG. Chỉ tạo QR sau khi đã có URL hoạt động.
Lưu ý: website GitHub Pages là công khai; đừng tải lên thông tin riêng tư.
